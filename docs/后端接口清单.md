# GeoView 后端接口清单与如实说明

## 0. 交付能力接口展开

### 0.1 多模态遥感数据目标自动配准

访问地址：`http://{backend_host}:{backend_port}/api/analysis/registration`

#### 接口描述

| 项目       | 说明                                                             |
| ---------- | ---------------------------------------------------------------- |
| 接口描述   | 对成对图像执行多模态自动配准，直接返回每一对配准结果摘要         |
| 调用地址   | `http://{backend_host}:{backend_port}/api/analysis/registration` |
| 调用方式   | 同步                                                             |
| 网络协议   | HTTP                                                             |
| 请求方法   | POST                                                             |
| 数据包格式 | `application/json`                                               |
| 输入描述   | 配准参数                                                         |
| 输出描述   | 每对配准结果及汇总信息                                           |

#### 请求参数和示例

##### a）参数说明

| 序号 | 字段名称            | 字段类型 | 是否必填 | 字段描述                                       |
| ---- | ------------------- | -------- | -------- | ---------------------------------------------- |
| 1    | `model_path`        | string   | 否       | 配准模型标识，默认 `builtin:registration:auto` |
| 2    | `list`              | list     | 是       | 图像对列表                                     |
| 3    | `list[*].first`     | string   | 是       | 参考图 URL                                     |
| 4    | `list[*].second`    | string   | 是       | 待配准图 URL                                   |
| 5    | `list[*].pair_name` | string   | 否       | 对名；不传则代码自动推导                       |

##### b）示例

```json
{
  "model_path": "builtin:registration:auto",
  "list": [
    {
      "first": "/_uploads/photos/fixed.tif",
      "second": "/_uploads/photos/moving.tif",
      "pair_name": "pair_001"
    }
  ]
}
```

#### 返回参数和示例

##### a）参数说明

顶层响应遵循 `success_api`，`data` 包含 `results` 与 `summary`。

`data.summary`：

| 字段名称        | 字段类型 | 字段描述       |
| --------------- | -------- | -------------- |
| `total_pairs`   | int      | 总对数         |
| `success_pairs` | int      | 成功对数       |
| `failed_pairs`  | int      | 失败对数       |
| `model_path`    | string   | 使用的模型标识 |

`data.results[*]` 常见字段：

| 字段名称               | 字段类型    | 字段描述             |
| ---------------------- | ----------- | -------------------- |
| `status`               | string      | `success` 或 `error` |
| `requested_model_path` | string      | 请求的模型标识       |
| `method_used`          | string/null | 实际采用的方法       |
| `transform_type`       | string/null | 变换类型             |
| `match_count`          | int         | 匹配点数             |
| `inlier_count`         | int         | 内点数               |
| `inlier_ratio`         | double      | 内点比例             |
| `rmse`                 | double/null | 配准误差             |
| `transform_matrix`     | list/null   | 变换矩阵             |
| `output_path`          | string/null | 配准结果图           |
| `overlay_path`         | string/null | 叠加图               |
| `checkerboard_path`    | string/null | 棋盘对比图           |
| `message`              | string      | 失败原因，失败时出现 |
| `fixed_input`          | string      | 参考图输入路径       |
| `moving_input`         | string      | 待配准图输入路径     |
| `fixed_name`           | string      | 参考图文件名         |
| `moving_name`          | string      | 待配准图文件名       |
| `pair_name`            | string      | 图像对名称           |

##### b）示例

```json
{
  "success": true,
  "code": 0,
  "msg": "配准完成，共 1/1 对成功",
  "data": {
    "results": [
      {
        "status": "success",
        "requested_model_path": "builtin:registration:auto",
        "method_used": "opencv_orb",
        "transform_type": "homography",
        "match_count": 128,
        "inlier_count": 73,
        "inlier_ratio": 0.5703,
        "rmse": 3.2811,
        "transform_matrix": [
          [1.0, 0.0, 12.3],
          [0.0, 1.0, -4.5],
          [0.0, 0.0, 1.0]
        ],
        "output_path": "/_uploads/photos/res/reg.png",
        "overlay_path": "/_uploads/photos/res/overlay.png",
        "checkerboard_path": "/_uploads/photos/res/checkerboard.png",
        "fixed_input": "/_uploads/photos/fixed.tif",
        "moving_input": "/_uploads/photos/moving.tif",
        "fixed_name": "fixed.tif",
        "moving_name": "moving.tif",
        "pair_name": "pair_001"
      }
    ],
    "summary": {
      "total_pairs": 1,
      "success_pairs": 1,
      "failed_pairs": 0,
      "model_path": "builtin:registration:auto"
    }
  }
}
```

### 0.3 干扰环境下小尺度目标检测

访问地址：`http://{backend_host}:{backend_port}/api/analysis/object_detection`

选用模型：`mmrotate:oriented_rcnn_r50_fpn_1x_dota_le90`

#### 接口描述

| 项目       | 说明                                                                                    |
| ---------- | --------------------------------------------------------------------------------------- |
| 接口描述   | 对上传后的单图或多图进行目标检测，支持 Paddle、本地 HuggingFace 前缀、MMRotate 前缀模型 |
| 调用地址   | `http://{backend_host}:{backend_port}/api/analysis/object_detection`                    |
| 调用方式   | 同步                                                                                    |
| 网络协议   | HTTP                                                                                    |
| 请求方法   | POST                                                                                    |
| 数据包格式 | `application/json`                                                                      |
| 输入描述   | 检测参数                                                                                |
| 输出描述   | 通用成功/失败响应，不直接回传检测框明细                                                 |

#### 请求参数和示例

##### a）参数说明

| 序号 | 字段名称     | 字段类型 | 是否必填 | 字段描述                                                       |
| ---- | ------------ | -------- | -------- | -------------------------------------------------------------- |
| 1    | `model_path` | string   | 是       | 模型路径或模型标识；支持本地路径、`hf:` 前缀、`mmrotate:` 前缀 |
| 2    | `list`       | list     | 是       | 待检测图片 URL 列表                                            |
| 3    | `prehandle`  | int      | 是       | 预处理，允许 `0/2/4`                                           |
| 4    | `denoise`    | int      | 是       | 降噪，允许 `0/3/5`                                             |

##### b）示例

```json
{
  "model_path": "mmrotate:oriented_rcnn_r50_fpn_1x_dota_le90",
  "list": [
    "/_uploads/photos/airport.png"
  ],
  "prehandle": 0,
  "denoise": 0
}
```

#### 返回参数和示例

##### a）参数说明

- 成功时返回通用成功响应
- 直接响应中不包含 `detections`、`bbox` 等检测结果字段
- 检测结果渲染图会入库，结构化框信息在该接口直接响应中未定义

##### b）示例

```json
{
  "success": true,
  "code": 0,
  "msg": "成功",
  "data": {}
}
```

### 0.6 遥感图像时序变化检测

访问地址：`http://{backend_host}:{backend_port}/api/analysis/change_detection`

#### 接口描述

| 项目       | 说明                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 接口描述   | 对上传后的双时相图像进行变化检测，可选预处理与降噪，并写入结果记录   |
| 调用地址   | `http://{backend_host}:{backend_port}/api/analysis/change_detection` |
| 调用方式   | 同步                                                                 |
| 网络协议   | HTTP                                                                 |
| 请求方法   | POST                                                                 |
| 数据包格式 | `application/json`                                                   |
| 输入描述   | 变化检测参数                                                         |
| 输出描述   | 通用成功/失败响应，不直接回传变化图明细                              |

#### 请求参数和示例

##### a）参数说明

| 序号 | 字段名称         | 字段类型 | 是否必填 | 字段描述             |
| ---- | ---------------- | -------- | -------- | -------------------- |
| 1    | `model_path`     | string   | 是       | 模型路径             |
| 2    | `list`           | list     | 是       | 图像对列表           |
| 3    | `list[*].first`  | string   | 是       | 第一时相图片 URL     |
| 4    | `list[*].second` | string   | 是       | 第二时相图片 URL     |
| 5    | `prehandle`      | int      | 是       | 预处理，允许 `0/1/4` |
| 6    | `denoise`        | int      | 是       | 降噪，允许 `0/3/5`   |
| 7    | `window_size`    | int      | 否       | 滑窗大小，默认 `256` |
| 8    | `stride`         | int      | 否       | 步长，默认 `128`     |

##### b）示例

```json
{
  "model_path": "model/change_detection/BIT",
  "list": [
    {
      "first": "/_uploads/photos/time1.png",
      "second": "/_uploads/photos/time2.png"
    }
  ],
  "prehandle": 0,
  "denoise": 0,
  "window_size": 256,
  "stride": 128
}
```

#### 返回参数和示例

##### a）参数说明

该接口成功时直接返回通用成功响应：

| 序号 | 字段名称  | 字段类型 | 字段描述   |
| ---- | --------- | -------- | ---------- |
| 1    | `success` | bool     | 是否成功   |
| 2    | `code`    | int      | 成功为 0   |
| 3    | `msg`     | string   | 提示信息   |
| 4    | `data`    | object   | 默认空对象 |

说明：

- 变化结果图、统计信息、孔洞填充结果等不在直接响应中返回，而是写入数据库记录并可通过历史/结果展示接口查询。

##### b）示例

```json
{
  "success": true,
  "code": 0,
  "msg": "成功",
  "data": {}
}
```

### 2.12.1 接口描述

| 请求方法   | POST                                                                       |

### 2.12.2 请求参数和示例

#### a）参数说明

| 序号 | 字段名称         | 字段类型 | 是否必填 | 字段描述          |
| ---- | ---------------- | -------- | -------- | ----------------- |
| 1    | `list`           | list     | 是       | 图像对列表        |
| 2    | `list[*].first`  | string   | 是       | 图 1 路径         |


### 2.12.3 返回参数和示例

#### a）参数说明

```json
{
```

## 2.13 图像预处理接口

### 2.13.1 接口描述

| 项目       | 说明                                                          |
| ---------- | ------------------------------------------------------------- |
| 接口描述   | 对单图列表或变化检测图像对执行预处理，并直接返回处理结果路径  |
| 调用地址   | `http://{backend_host}:{backend_port}/api/analysis/image_pre` |
| 调用方式   | 同步                                                          |
| 网络协议   | HTTP                                                          |
| 请求方法   | POST                                                          |
| 数据包格式 | `application/json`                                            |
| 输入描述   | 图像列表、预处理参数、任务类型                                |
| 输出描述   | 预处理结果                                                    |

### 2.13.2 请求参数和示例

#### a）参数说明

| 序号 | 字段名称    | 字段类型 | 是否必填 | 字段描述                                                    |
| ---- | ----------- | -------- | -------- | ----------------------------------------------------------- |
| 1    | `list`      | list     | 是       | 单图任务时为路径数组；变化检测场景时为对象数组              |
| 2    | `prehandle` | int      | 是       | 仅允许 `2` 或 `4`                                           |
| 3    | `type`      | int      | 是       | 任务类型；当 `type == 1` 时按图像对处理，否则按单图列表处理 |

变化检测场景下 `list[*]`：

| 字段名称 | 字段类型 | 字段描述 |
| -------- | -------- | -------- |
| `first`  | string   | 图 1     |
| `second` | string   | 图 2     |

#### b）示例

单图列表：

```json
{
  "list": [
    "/_uploads/photos/img1.png"
  ],
  "prehandle": 2,
  "type": 2
}
```

图像对：

```json
{
  "list": [
    {
      "first": "/_uploads/photos/a.png",
      "second": "/_uploads/photos/b.png"
    }
  ],
  "prehandle": 4,
  "type": 1
}
```

### 2.13.3 返回参数和示例

#### a）参数说明

当 `type != 1` 时，`data` 为字符串数组：

| 字段名称  | 字段类型 | 字段描述       |
| --------- | -------- | -------------- |
| `data[*]` | string   | 处理后图片路径 |

当 `type == 1` 时，`data[*]` 为对象数组：

| 字段名称  | 字段类型 | 字段描述   |
| --------- | -------- | ---------- |
| `first`   | string   | 原图 1     |
| `first1`  | string   | 处理后图 1 |
| `second`  | string   | 原图 2     |
| `second1` | string   | 处理后图 2 |

#### b）示例

```json
{
  "success": true,
  "code": 0,
  "msg": "成功",
  "data": [
    "/_uploads/photos/res/img1_clahe.png"
  ]
}
```

### 2.13.4 接口约束和异常

#### a）约束

- `prehandle` 仅允许 `2` 或 `4`
- `list` 不能为空
- 当 `type == 1` 时，列表元素必须带 `first` 和 `second`

#### b）异常

- `请上传图片`
- `请求参数异常`
