## 一步一步操作

### 第 1 步：把 Thin 包放到一个单独目录

比如你可以放到：

```bash
~/delivery/
```

假设你已经把文件放好了：

```text
~/delivery/GeoView_Offline_Thin_YYYYMMDD.tar.gz
```

### 第 2 步：解压 Thin 包

执行：

```bash
cd ~/delivery
tar -xzf GeoView_Offline_Thin_*.tar.gz
cd GeoView
```

进入 `GeoView` 后，你应该能看到这些文件：

- `deploy_offline.sh`
- `export_offline.sh`
- `docker-compose.yml`
- `backend/`
- `docs/`

### 第 3 步：登录阿里云镜像仓库

执行：

```bash
docker login --username=13997543646yqx crpi-4r2gidb79yjyny4o.cn-hangzhou.personal.cr.aliyuncs.com
```

输入密码：

```text
Yqx123123123
```

如果看到 `Login Succeeded`，说明登录成功。

### 第 4 步：启动中转环境

确保你当前就在 `GeoView` 目录里，然后执行：

```bash
./deploy_offline.sh
```

这个命令会自动做这些事情：

1. 检查和修正 `offline_cache/` 目录权限
2. 从 `backend/model/` 生成运行时缓存
3. 检查模型文件是否完整
4. 自动拉取 GeoView 应用镜像
5. 自动拉取 MySQL 镜像
6. 启动 GeoView 和 MySQL 容器

这一步可能要等几分钟，属于正常现象。

### 第 5 步：检查系统是否启动成功

先看容器状态：

```bash
docker compose ps
```

如果你看到：

- `cugrs-app` 是 `Up`
- `cugrs-mysql` 是 `Up`

就说明容器启动成功了。

然后再看一下日志：

```bash
docker logs -f cugrs-app
```

如果没有一直报错，按：

```bash
Ctrl + C
```

退出日志查看。

### 第 6 步：用浏览器简单确认一下

在中转机器浏览器打开：

```text
http://127.0.0.1:3000
```

如果页面能打开，说明这一步基本没问题。

### 第 7 步：导出 Full 包

确认系统已经能正常启动后，回到终端，仍然在 `GeoView` 目录里，执行：

```bash
./export_offline.sh 1
```

这一步会把完整内容打包出来，包括：

1. 项目代码
2. 统一模型目录 `backend/model/`
3. 运行缓存 `offline_cache/`
4. GeoView 应用镜像 tar
5. MySQL 镜像 tar

这一步通常也会比较久，请耐心等待。

### 第 8 步：找到生成好的 Full 包

Full 包不会放在当前 `GeoView` 目录里，而是放在它的上一级目录。

如果你当前目录是：

```text
~/delivery/GeoView
```

那么生成结果通常在：

```text
~/delivery/GeoView_Offline_Full_YYYYMMDD.tar.gz
```

你可以执行：

```bash
cd ..
ls -lh GeoView_Offline_Full_*.tar.gz
```

确认文件已经生成。

## 最容易出错的地方

### 1. 不要执行错命令

中转机器一定要执行：

```bash
./export_offline.sh 1
```

不要执行：

```bash
./export_offline.sh 2
```

因为：

- `2` 是源机器导出 Thin 包用的
- `1` 才是中转机器导出 Full 包用的

### 2. 如果提示拉取镜像失败

先重新执行登录：

```bash
docker login --username=13997543646yqx crpi-4r2gidb79yjyny4o.cn-hangzhou.personal.cr.aliyuncs.com
```

再重新执行：

```bash
./deploy_offline.sh
```

### 3. 如果提示磁盘空间不足

中转机器要有比较大的剩余空间。

因为这一步会同时存在：

- 解压后的项目文件
- Docker 镜像
- 离线缓存
- 最终 Full 包

### 4. 如果不确定自己现在在哪个目录

执行：

```bash
pwd
```

正常情况下，在执行 `deploy_offline.sh` 和 `export_offline.sh 1` 前，你应该位于：

```text
.../GeoView
```
