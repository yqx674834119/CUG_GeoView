# 1 范围

## 1.1 标识
本文档标识的系统为 **遥感目标图像识别产品 v2.0**（以下简称“本产品”），主要针对其核心算法模块进行测试。版本号：2.0.0。

## 1.2 系统概述
本产品旨在利用多模态遥感数据（光学与SAR），在复杂干扰环境下实现高精度的目标检测、识别、超分重建及变化检测预警能力。

### 1.2.1 功能模块
本产品包含以下核心功能模块：
a) **多模态遥感数据目标自动配准**；
b) **多模态遥感数据特征级融合**；
c) **干扰环境下小尺度目标检测**；
d) **遥感图像超分重建**；
e) **细粒度遥感目标检测**；
f) **遥感图像时序变化检测**；
g) **多目标变化检测**；
h) **全域静态目标跟踪与预警能力**。

### 1.2.2 CSCI关键等级
本产品核心算法软件为 **C级** 软件。
