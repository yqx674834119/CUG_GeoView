## 第二条 字体规范

本章节包括字体种类、字体大小、字体颜色、字体间距和对齐方式五部分内容。

### (一) 字体种类
字体种类的设计要求如下：
1.  **中英文与数字字体**：统一使用阿里巴巴普惠体（无衬线字体），允许对文本采用加粗、倾斜、下划线等样式，字重 Regular（标准）、Bold（粗）。
2.  **特殊文字**：优设标题黑。特效文字或者特殊字体的文字一般使用图片格式，防止由于客户端缺少某种字体而影响整体效果。
3.  **标点符号**：遵循中文标点符号标准。
4.  **文字用语**：尽量用肯定句而不要用否定句；用主动语态而不用被动语态；用礼貌而不过分的强调语句进行文字会话；在按钮，功能键标示中应尽量使用描述操作的动词。

### (二) 字体大小
字体大小分为小、标准、大、超大、特大 5 个等级。
* **字重**：Regular（标准）、Bold（粗）。
* **常规字体**：阿里巴巴普惠字体。
* **特殊字体**：优设标题黑（没有字重）。
* **行高**：字体 + 8px。

### (三) 字体颜色
字体颜色根据主题而定，具体要求如下：
1.  浅色主题下默认字体颜色为 Rgb(51, 51, 51)。
2.  深色主题下默认字体颜色为 Rgb(255, 255, 255)。

### (四) 字体间距
文字设计的间距规范包括字间距、行间距与段间距三种类型：
1.  **字间距**：包括标准、加宽与紧缩三种类型，也可以采用“百分比 + 标准字间距”的描述形式，如“200% 标准字间距”、“80% 标准字间距”。
2.  **行间距**：主要约束界面中的文字段落，依据段落字体的大小选 1-1.5 倍作为行间距，比如 16 号字体，行间距是 16px-24px。
3.  **段间距**：主要约束界面中的文字段落，要求段间距大于行间距，宜选择段落字体大小的 1.5-2 倍作为段间距，比如 16 号字体，段间距是 24px-32px。

### (五) 对齐方式
文字的对齐方式包括左对齐、居中对齐、右对齐、两端对齐、首行缩进、悬挂缩进等类型：
1.  对于控件中使用的文字，对齐方式主要为**左对齐**；按钮控件中文字的对齐方式宜为**居中对齐**。
2.  对于界面中的文本段落，正文内容文字宜为**左对齐**；标题文字宜为**居中对齐**。对于文本段落的对齐方式，可依据使用情境选用其他对齐方式。
